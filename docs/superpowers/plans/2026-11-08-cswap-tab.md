# Accounts tab (cswap) implementation plan

Spec: `docs/superpowers/specs/2026-11-08-cswap-tab-design.md`.

1. **Core (tested)**: `MuDoCore/Cswap.swift` with `CswapList.parse`, `CswapRowModel`, `CswapSeverity`, `CswapPaths`, `CswapCommand`; `CswapTests.swift` covers parsing, fallbacks, row rules, paths and arguments. Run `swift test` on the Mac.
2. **Glue**: `MuDo/CswapModel.swift` finds the binary in fixed paths, runs `cswap` without a shell (20 s timeout), exposes `accounts`, `error`, `loading`, `switching`; `AppModel.cswap`.
3. **UI**: `PanelTab` + `TabBar` in `RootView` (only when `cswap` is found and the setting is on), `AccountViews.swift` (list, row, usage bar), tab resets to Sessions on collapse (`PanelState.tab`).
4. **Setting**: `AppSettings.showAccountsTab` (default on), toggle in Settings when `cswap` exists.
5. **Docs**: README section "Accounts tab (cswap)".
6. **Verify**: `swift test`, `make install` on the Mac, render the row views with real `cswap list --json` output. A live `cswap switch` is not run in automated checks because it changes the user's active account.
