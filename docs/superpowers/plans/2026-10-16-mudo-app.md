# MuDo Mac App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `MuDo.app`, a floating macOS widget that streams Claude Code / Kiro CLI session states from one or more `mudod` servers, blinks on forgotten finished sessions, and focuses the session's code-server Chrome window on click.

**Architecture:** One Swift package in `app/`. `MuDoCore` (library) holds every piece of logic that can be tested without AppKit: wire models, SSE parser, session store, tab matching, reconnect loop with an injected transport. It builds on macOS and Linux. `MuDo` (executable, macOS only) is a thin AppKit/SwiftUI shell: `NSPanel`, views, URLSession transport, Keychain, AppleScript. A `Makefile` wraps the executable into an ad-hoc signed `MuDo.app` bundle.

**Tech Stack:** Swift 6.2 toolchain, Swift 6 language mode, SwiftUI + AppKit, Observation, Swift Testing, Foundation `URLSession`, Security (Keychain), ServiceManagement, Network (`NWPathMonitor`), `NSAppleScript`. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-10-14-mudo-design.md` sections 5, 6, 7, 8. Server side (`mudod`) is done and installed on `devbox`.

## Global Constraints

- Platform: macOS 26.0 or later (`platforms: [.macOS("26.0")]`). Target user machine runs macOS 26.5.1 (25F80).
- No third-party dependencies. Swift 6 language mode (`swiftLanguageModes: [.v6]`), strict concurrency, no `@preconcurrency` imports, no `nonisolated(unsafe)`.
- `MuDoCore` must compile on Linux too: only `Foundation` and `Observation` imports, no AppKit/SwiftUI/Security/Darwin-only API (no `URLSession.bytes`, no `os.Logger`).
- Tests use Swift Testing (`import Testing`, `@Test`, `#expect`, `#require`), not XCTest.
- Bundle identifier: `dev.steve.MuDo`. Keychain service: `dev.steve.MuDo`. URL scheme: `mudo`.
- App is not sandboxed, ad-hoc signed (`codesign --sign -`), `LSUIElement = YES`, `NSAppTransportSecurity.NSAllowsArbitraryLoads = YES` (daemons are plain HTTP over Tailscale).
- Protocol (spec 5): `GET <daemon>/v1/stream` (SSE: `snapshot`, `upsert`, `remove`, `ping` every 15 s), `POST <daemon>/v1/sessions/{id}/ack` (204 ok, 404 unknown, 409 not done), header `Authorization: Bearer <token>`, 401 on bad token. JSON keys are snake_case; timestamps are RFC 3339 UTC with up to 9 fractional digits (Go `time.Time`).
- `state` ∈ `idle | running | waiting | done | ended`. `ended` is never shown.
- Defaults: stale after 5 min, snooze 10 min, menu "Pause blinking" 1 h, hover collapse delay 1.5 s, reconnect backoff 1 s doubling to 30 s max, stream idle timeout 45 s, blink 1 Hz (0.5 s on / 0.5 s off).
- Sort: waiting → stale → done → running → idle; inside a bucket, oldest `state_since` first.
- Clock offset per server: `offset = server_now − local_now` on every message; local time of a server instant = instant − offset.
- Sessions of a non-connected server are shown dimmed with a `?` and never blink.
- Colors: running blue, waiting orange, done/stale green, idle secondary.
- Mac commands: run through `app/scripts/on-mac <command>` (rsync `app/` to the Mac, run there). Requires `MUDO_MAC=user@host` in the environment; for this project `MUDO_MAC=user@192.168.1.20` (MacBook Pro, macOS 26.5.1, Xcode 26.4, reached over the LAN; server-to-Mac traffic over Tailscale is blocked). Linux-side `swift` is optional; when present, `cd app && swift test` runs the `MuDoCore` tests locally.

```swift
import Foundation

public enum SessionState: String, Codable, Sendable {
    case idle, running, waiting, done, ended
}

/// One agent session as sent by mudod (spec 5). Extra server fields are ignored.
public struct Session: Codable, Equatable, Identifiable, Sendable {
    public var id: String
    public var agent: String
    public var host: String
    public var cwd: String
    public var project: String
    public var state: SessionState
    public var stateSince: Date
    public var lastPrompt: String

    public init(id: String, agent: String, host: String, cwd: String, project: String,
                state: SessionState, stateSince: Date, lastPrompt: String) {
        self.id = id
        self.agent = agent
        self.host = host
        self.cwd = cwd
        self.project = project
        self.state = state
        self.stateSince = stateSince
        self.lastPrompt = lastPrompt
    }
}

public enum StreamMessage: Equatable, Sendable {
    case snapshot(serverNow: Date, host: String, sessions: [Session])
    case upsert(serverNow: Date, session: Session)
    case remove(serverNow: Date, id: String)
    case ping(serverNow: Date)

    public var serverNow: Date {
        switch self {
        case let .snapshot(now, _, _), let .upsert(now, _), let .remove(now, _), let .ping(now):
            return now
        }
    }

    /// Decodes one SSE event. Returns nil for event names the app does not know.
    public static func decode(event: String, data: String) throws -> StreamMessage? {
        let bytes = Data(data.utf8)
        let decoder = WireDate.decoder()
        switch event {
        case "snapshot":
            let m = try decoder.decode(SnapshotWire.self, from: bytes)
            return .snapshot(serverNow: m.serverNow, host: m.host, sessions: m.sessions ?? [])
        case "upsert":
            let m = try decoder.decode(UpsertWire.self, from: bytes)
            return .upsert(serverNow: m.serverNow, session: m.session)
        case "remove":
            let m = try decoder.decode(RemoveWire.self, from: bytes)
            return .remove(serverNow: m.serverNow, id: m.id)
        case "ping":
            let m = try decoder.decode(PingWire.self, from: bytes)
            return .ping(serverNow: m.serverNow)
        default:
            return nil
        }
    }
}

private struct SnapshotWire: Decodable {
    let serverNow: Date
    let host: String
    let sessions: [Session]?
}

private struct UpsertWire: Decodable {
    let serverNow: Date
    let session: Session
}

private struct RemoveWire: Decodable {
    let serverNow: Date
    let id: String
}

private struct PingWire: Decodable {
    let serverNow: Date
}

public enum WireDate {
    /// Parses RFC 3339 timestamps with any number of fractional digits (Go emits up to 9).
    public static func parse(_ text: String) -> Date? {
        var base = text
        var fraction = 0.0
        if let dot = text.firstIndex(of: ".") {
            let rest = text[text.index(after: dot)...]
            let digits = rest.prefix(while: { $0.isASCII && $0.isNumber })
            guard !digits.isEmpty else { return nil }
            fraction = Double("0." + digits) ?? 0
            base = String(text[..<dot]) + String(rest.dropFirst(digits.count))
        }
        let formatter = ISO8601DateFormatter()
        formatter.formatOptions = [.withInternetDateTime]
        guard let date = formatter.date(from: base) else { return nil }
        return date.addingTimeInterval(fraction)
    }

    static func decoder() -> JSONDecoder {
        let decoder = JSONDecoder()
        decoder.keyDecodingStrategy = .convertFromSnakeCase
        decoder.dateDecodingStrategy = .custom { d in
            let container = try d.singleValueContainer()
            let text = try container.decode(String.self)
            guard let date = parse(text) else {
                throw DecodingError.dataCorruptedError(in: container, debugDescription: "bad timestamp \(text)")
            }
            return date
        }
        return decoder
    }
}
```

```swift
public struct SSEEvent: Equatable, Sendable {
    public var event: String
    public var data: String

    public init(event: String, data: String) {
        self.event = event
        self.data = data
    }
}

/// Incremental Server-Sent Events parser (WHATWG event-stream format).
/// Lines end with CRLF, LF or CR; an empty line dispatches the pending event.
public struct SSEParser: Sendable {
    private static let maxLine = 1 << 20

    private var line: [UInt8] = []
    private var afterCR = false
    private var eventName = ""
    private var dataLines: [String] = []

    public init() {}

    public mutating func feed<S: Sequence>(_ bytes: S) -> [SSEEvent] where S.Element == UInt8 {
        var out: [SSEEvent] = []
        for byte in bytes {
            if afterCR {
                afterCR = false
                if byte == 0x0A { continue }
            }
            if byte == 0x0A || byte == 0x0D {
                afterCR = byte == 0x0D
                let text = String(decoding: line, as: UTF8.self)
                line.removeAll(keepingCapacity: true)
                if let event = process(text) { out.append(event) }
            } else if line.count < Self.maxLine {
                line.append(byte)
            }
        }
        return out
    }

    private mutating func process(_ text: String) -> SSEEvent? {
        if text.isEmpty {
            defer {
                eventName = ""
                dataLines = []
            }
            guard !dataLines.isEmpty else { return nil }
            return SSEEvent(event: eventName.isEmpty ? "message" : eventName,
                            data: dataLines.joined(separator: "\n"))
        }
        if text.hasPrefix(":") { return nil }
        let field: Substring
        var value: Substring = ""
        if let colon = text.firstIndex(of: ":") {
            field = text[..<colon]
            value = text[text.index(after: colon)...]
            if value.hasPrefix(" ") { value = value.dropFirst() }
        } else {
            field = Substring(text)
        }
        switch field {
        case "event": eventName = String(value)
        case "data": dataLines.append(String(value))
        default: break
        }
        return nil
    }
}
```

```swift
    public var codeServerURL: URL?

/// `mudo://add?name=<n>&url=<daemon url>&token=<t>[&code_server=<url>]`
public enum AddLink {
    public static func parse(_ url: URL) -> ServerDraft? {
        guard let comps = URLComponents(url: url, resolvingAgainstBaseURL: false),
              comps.scheme?.lowercased() == "mudo",
              comps.host?.lowercased() == "add" else { return nil }
        let items = comps.queryItems ?? []
        func value(_ name: String) -> String? {
            guard let v = items.first(where: { $0.name == name })?.value, !v.isEmpty else { return nil }
            return v
        }
        guard let token = value("token"),
              let daemon = value("url").flatMap(httpURL) else { return nil }
        let host = URLComponents(url: daemon, resolvingAgainstBaseURL: false)?.host ?? "server"
        return ServerDraft(name: value("name") ?? host,
                           daemonURL: daemon,
                           token: token,
                           codeServerURL: value("code_server").flatMap(httpURL))
    }

    /// An http(s) URL with a host, or nil.
    public static func httpURL(_ text: String) -> URL? {
        guard let comps = URLComponents(string: text.trimmingCharacters(in: .whitespaces)),
              let scheme = comps.scheme?.lowercased(), scheme == "http" || scheme == "https",
              let host = comps.host, !host.isEmpty else { return nil }
        return comps.url
    }
}
```

```swift
import Foundation

public enum ElapsedFormat {
    /// "12s", "7m", "1h", "1h 5m".
    public static func short(_ seconds: TimeInterval) -> String {
        let s = max(0, Int(seconds))
        if s < 60 { return "\(s)s" }
        if s < 3600 { return "\(s / 60)m" }
        let h = s / 3600
        let m = (s % 3600) / 60
        return m == 0 ? "\(h)h" : "\(h)h \(m)m"
    }
}

public enum PanelPlacement {
    /// Where to put the panel's top-left corner (AppKit coordinates).
    /// Keeps `saved` while a point just inside it is on some screen; otherwise the main
    /// screen's top-right corner, inset by `margin`.
    public static func topLeft(saved: CGPoint?, screens: [CGRect], main: CGRect?,
                               width: CGFloat, margin: CGFloat = 12) -> CGPoint? {
        if let p = saved {
            let probe = CGPoint(x: p.x + 10, y: p.y - 10)
            if screens.contains(where: { contains($0, probe) }) { return p }
        }
        guard let m = main else { return saved }
        return CGPoint(x: m.maxX - width - margin, y: m.maxY - margin)
    }

    private static func contains(_ r: CGRect, _ p: CGPoint) -> Bool {
        p.x >= r.minX && p.x < r.maxX && p.y >= r.minY && p.y < r.maxY
    }
}
```

```swift
import Foundation
import Observation

public struct SessionKey: Hashable, Sendable {
    public let serverID: UUID
    public let sessionID: String

    public init(serverID: UUID, sessionID: String) {
        self.serverID = serverID
        self.sessionID = sessionID
    }
}

public enum ConnectionStatus: Equatable, Sendable {
    case connecting, connected, offline, unauthorized
}

public struct ServerRow: Identifiable, Equatable, Sendable {
    public let id: UUID
    public let name: String
    public let status: ConnectionStatus

    public init(id: UUID, name: String, status: ConnectionStatus) {
        self.id = id
        self.name = name
        self.status = status
    }
}

/// Merges the session streams of every configured server (spec 6.3, 6.6).
@MainActor
@Observable
public final class SessionStore {
    struct ServerState {
        var name: String
        var status: ConnectionStatus = .connecting
        var offset: TimeInterval = 0
        var sessions: [String: Session] = [:]
    }

    public var staleAfter: TimeInterval = 300
    public var snoozeFor: TimeInterval = 600
    public private(set) var now: Date

    var serverStates: [UUID: ServerState] = [:]
    var order: [UUID] = []
    var snoozedUntil: [SessionKey: Date] = [:]
    var pausedUntil: Date?
    private var failedAcks: Set<SessionKey> = []
    @ObservationIgnored private let clock: @Sendable () -> Date

    public init(clock: @escaping @Sendable () -> Date = { Date() }) {
        self.clock = clock
        self.now = clock()
    }

    // MARK: Servers

    public func setServers(_ configs: [ServerConfig]) {
        var next: [UUID: ServerState] = [:]
        for config in configs {
            var state = serverStates[config.id] ?? ServerState(name: config.name)
            state.name = config.name
            next[config.id] = state
        }
        serverStates = next
        order = configs.map(\.id)
        failedAcks = failedAcks.filter { next[$0.serverID] != nil }
        pruneSnoozes()
    }

    public func status(of serverID: UUID) -> ConnectionStatus? {
        serverStates[serverID]?.status
    }

    public func setStatus(_ status: ConnectionStatus, for serverID: UUID) {
        guard serverStates[serverID] != nil, serverStates[serverID]?.status != status else { return }
        serverStates[serverID]?.status = status
    }

    public func offset(of serverID: UUID) -> TimeInterval? {
        serverStates[serverID]?.offset
    }

    public var servers: [ServerRow] {
        order.compactMap { id in
            serverStates[id].map { ServerRow(id: id, name: $0.name, status: $0.status) }
        }
    }

    public var problemServers: [ServerRow] {
        servers.filter { $0.status != .connected }
    }

    public var hasMultipleServers: Bool { serverStates.count > 1 }

    // MARK: Stream messages

    @discardableResult
    public func apply(_ message: StreamMessage, from serverID: UUID) -> [SessionKey] {
        guard var server = serverStates[serverID] else { return [] }
        now = clock()
        server.offset = message.serverNow.timeIntervalSince(now)
        var retries: [SessionKey] = []
        switch message {
        case let .snapshot(_, _, sessions):
            server.sessions = Dictionary(sessions.map { ($0.id, $0) }, uniquingKeysWith: { _, last in last })
            for key in failedAcks where key.serverID == serverID {
                if server.sessions[key.sessionID]?.state == .done { retries.append(key) }
            }
            failedAcks = failedAcks.filter { $0.serverID != serverID }
        case let .upsert(_, session):
            server.sessions[session.id] = session
        case let .remove(_, id):
            server.sessions[id] = nil
        case .ping:
            break
        }
        serverStates[serverID] = server
        pruneSnoozes()
        return retries
    }

    public func markAckFailed(_ key: SessionKey) {
        failedAcks.insert(key)
    }

    public func session(_ key: SessionKey) -> Session? {
        serverStates[key.serverID]?.sessions[key.sessionID]
    }

    // MARK: Time

    public func tick() {
        now = clock()
        snoozedUntil = snoozedUntil.filter { $0.value > now }
        if let until = pausedUntil, until <= now { pausedUntil = nil }
    }

    /// Snoozes only make sense for sessions that are still `done`.
    func pruneSnoozes() {
        snoozedUntil = snoozedUntil.filter { session($0.key)?.state == .done }
    }
}
```

```swift
extension SessionStore {
    public var isPaused: Bool {
        guard let until = pausedUntil else { return false }
        return until > now
    }

    public func pause(for duration: TimeInterval) {
        tick()
        pausedUntil = now.addingTimeInterval(duration)
    }

    public func resume() {
        pausedUntil = nil
    }

    public func snooze(_ key: SessionKey) {
        guard session(key)?.state == .done else { return }
        tick()
        snoozedUntil[key] = now.addingTimeInterval(snoozeFor)
    }

    public func clearSnooze(_ key: SessionKey) {
        snoozedUntil[key] = nil
    }

    public var rows: [SessionRow] {
        let paused = isPaused
        var out: [SessionRow] = []
        for (serverID, server) in serverStates {
            let offline = server.status != .connected
            for s in server.sessions.values where s.state != .ended {
                let key = SessionKey(serverID: serverID, sessionID: s.id)
                let since = s.stateSince.addingTimeInterval(-server.offset)
                let elapsed = max(0, now.timeIntervalSince(since))
                let bucket: Bucket = switch s.state {
                case .waiting: .waiting
                case .done: elapsed >= staleAfter ? .stale : .done
                case .running: .running
                case .idle, .ended: .idle
                }
                let snoozed = snoozedUntil[key].map { $0 > now } ?? false
                out.append(SessionRow(
                    id: key, session: s, serverName: server.name, bucket: bucket,
                    since: since, elapsed: elapsed,
                    blinking: bucket == .stale && !snoozed && !paused && !offline,
                    offline: offline))
            }
        }
        return out.sorted { a, b in
            if a.bucket != b.bucket { return a.bucket < b.bucket }
            if a.since != b.since { return a.since < b.since }
            if a.id.serverID != b.id.serverID { return a.id.serverID.uuidString < b.id.serverID.uuidString }
            return a.id.sessionID < b.id.sessionID
        }
    }

    public var pill: PillSummary {
        let all = rows
        return PillSummary(
            running: all.count(where: { $0.bucket == .running }),
            waiting: all.count(where: { $0.bucket == .waiting }),
            done: all.count(where: { $0.bucket == .done || $0.bucket == .stale }),
            blinking: all.contains(where: \.blinking),
            offline: serverStates.values.allSatisfy { $0.status != .connected })
    }
```

```swift
import Foundation

public struct ChromeTab: Equatable, Sendable {
    public var windowID: Int
    public var tabIndex: Int
    public var url: String
    public var title: String

    public init(windowID: Int, tabIndex: Int, url: String, title: String) {
        self.windowID = windowID
        self.tabIndex = tabIndex
        self.url = url
        self.title = title
    }
}

/// Picks the Chrome tab showing a session's code-server workspace (spec 6.4).
public enum TabMatcher {
    public static func targetURL(codeServer: URL, cwd: String) -> URL {
        var comps = URLComponents(url: codeServer, resolvingAgainstBaseURL: false) ?? URLComponents()
        if !comps.path.hasSuffix("/") { comps.path += "/" }
        comps.queryItems = [URLQueryItem(name: "folder", value: cwd)]
        return comps.url ?? codeServer
    }

    public static func match(tabs: [ChromeTab], codeServer: URL, cwd: String, project: String) -> ChromeTab? {
        guard let base = URLComponents(url: codeServer, resolvingAgainstBaseURL: false) else { return nil }
        let candidates = tabs.filter { isUnder(base, $0.url) }
        let want = trimSlash(cwd)
        if let hit = candidates.first(where: { folder(of: $0.url).map(trimSlash) == want }) {
            return hit
        }
        let middle = " \u{2014} \(project) \u{2014} "
        let leading = "\(project) \u{2014} "
        return candidates.first { $0.title.contains(middle) || $0.title.hasPrefix(leading) }
    }

    static func isUnder(_ base: URLComponents, _ text: String) -> Bool {
        guard let u = URLComponents(string: text),
              u.scheme?.lowercased() == base.scheme?.lowercased(),
              u.host?.lowercased() == base.host?.lowercased(),
              port(u) == port(base) else { return false }
        let prefix = trimSlash(base.path)
        if prefix.isEmpty { return true }
        return u.path == prefix || u.path.hasPrefix(prefix + "/")
    }

    static func port(_ c: URLComponents) -> Int? {
        if let p = c.port { return p }
        switch c.scheme?.lowercased() {
        case "http": return 80
        case "https": return 443
        default: return nil
        }
    }

    static func folder(of text: String) -> String? {
        URLComponents(string: text)?.queryItems?.first(where: { $0.name == "folder" })?.value
    }

    static func trimSlash(_ path: String) -> String {
        var p = Substring(path)
        while p.hasSuffix("/") { p = p.dropLast() }
        return String(p)
    }
}

/// AppleScript sources sent to Google Chrome. Kept here so they are testable on any OS.
public enum ChromeScripts {
    /// Returns a list of {window id, tab index, URL, title}.
    public static let listTabs = """
    tell application id "com.google.Chrome"
        set out to {}
        repeat with w in windows
            set ti to 0
            repeat with t in tabs of w
                set ti to ti + 1
                set end of out to {id of w, ti, URL of t, title of t}
            end repeat
        end repeat
        return out
    end tell
    """

    public static func focus(_ tab: ChromeTab) -> String {
        """
        tell application id "com.google.Chrome"
            set w to window id \(tab.windowID)
            if minimized of w then set minimized of w to false
            set active tab index of w to \(tab.tabIndex)
            set index of w to 1
            activate
        end tell
        """
    }

    public static func newWindow(_ url: URL) -> String {
        """
        tell application id "com.google.Chrome"
            set w to make new window
            set URL of active tab of w to \(quoted(url.absoluteString))
            activate
        end tell
        """
    }

    public static func quoted(_ text: String) -> String {
        let escaped = text
            .replacingOccurrences(of: "\\", with: "\\\\")
            .replacingOccurrences(of: "\"", with: "\\\"")
        return "\"\(escaped)\""
    }
}
```

- `stop()` cancels; a cancelled loop never touches the store again.
- `reconnectNow()`: no-op when status is `.unauthorized`; otherwise stop, reset backoff, start.

```swift
final class FakeTransport: EventTransport, @unchecked Sendable {
    enum Attempt {
        case events([SSEEvent], end: (any Error)?)
        case eventsThenHang([SSEEvent])
        case hang
    }

    private let lock = NSLock()
    private var attempts: [Attempt]
    private var _calls: [(URL, String)] = []

    init(_ attempts: [Attempt]) { self.attempts = attempts }

    var calls: [(URL, String)] { lock.withLock { _calls } }

    func events(url: URL, token: String) -> AsyncThrowingStream<SSEEvent, any Error> {
        let attempt: Attempt = lock.withLock {
            _calls.append((url, token))
            return attempts.isEmpty ? .hang : attempts.removeFirst()

        return AsyncThrowingStream { continuation in
            switch attempt {
            case let .events(events, end):

                continuation.finish(throwing: end)
            case let .eventsThenHang(events):
                for e in events { continuation.yield(e) }
            case .hang:

            }
        }
    }
```

```swift
import Foundation

public struct Backoff: Sendable {
    public let initial: Duration
    public let maximum: Duration
    private var current: Duration?

    public init(initial: Duration = .seconds(1), maximum: Duration = .seconds(30)) {
        self.initial = initial
        self.maximum = maximum
    }

    public mutating func next() -> Duration {
        let value = current.map { min($0 * 2, maximum) } ?? initial
        current = value
        return value
    }

    public mutating func reset() {
        current = nil
    }
}

public enum StreamError: Error, Equatable {
    case unauthorized
    case http(Int)
}

/// Opens the daemon's SSE stream. Throws `StreamError.unauthorized` on HTTP 401.
public protocol EventTransport: Sendable {
    func events(url: URL, token: String) -> AsyncThrowingStream<SSEEvent, any Error>
}

/// One live SSE connection to one mudod server, with reconnect (spec 6.6).
@MainActor
public final class ServerConnection {
    public let config: ServerConfig
    private let token: String
    private let store: SessionStore
    private let transport: any EventTransport
    private let sleep: @Sendable (Duration) async throws -> Void
    private let onAckRetry: @MainActor ([SessionKey]) -> Void
    private var backoff = Backoff()
    private var task: Task<Void, Never>?

    public init(config: ServerConfig, token: String, store: SessionStore, transport: any EventTransport,
                sleep: @escaping @Sendable (Duration) async throws -> Void = { try await Task.sleep(for: $0) },
                onAckRetry: @escaping @MainActor ([SessionKey]) -> Void = { _ in }) {
        self.config = config
        self.token = token
        self.store = store
        self.transport = transport
        self.sleep = sleep
        self.onAckRetry = onAckRetry
    }

    public var streamURL: URL {
        config.daemonURL.appending(path: "v1/stream")
    }

    public func start() {
        guard task == nil else { return }
        store.setStatus(.connecting, for: config.id)
        task = Task { [weak self] in
            await self?.run()
        }
    }

    public func stop() {
        task?.cancel()
        task = nil
    }

    public func reconnectNow() {
        guard store.status(of: config.id) != .unauthorized else { return }
        stop()
        backoff.reset()
        start()
    }

    private func run() async {
        while !Task.isCancelled {
            var connected = false
            do {
                for try await event in transport.events(url: streamURL, token: token) {
                    if Task.isCancelled { return }
                    guard let message = try? StreamMessage.decode(event: event.event, data: event.data) else {
                        continue
                    }
                    if !connected {
                        connected = true
                        backoff.reset()
                        store.setStatus(.connected, for: config.id)
                    }
                    let retries = store.apply(message, from: config.id)
                    if !retries.isEmpty { onAckRetry(retries) }
                }
            } catch StreamError.unauthorized {
                if Task.isCancelled { return }
                store.setStatus(.unauthorized, for: config.id)
                task = nil
                return
            } catch {
                // Network error or HTTP error: fall through to the retry path.
            }
            if Task.isCancelled { return }
            store.setStatus(.offline, for: config.id)
            do {
                try await sleep(backoff.next())
            } catch {
                return
            }
        }
    }
}
```

```swift
import Foundation
import Security

/// Generic-password items under service `dev.steve.MuDo`, one per server id.
enum Keychain {
    static let service = "dev.steve.MuDo"

    private static func query(_ account: String) -> [String: Any] {
        [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: account,
        ]
    }

    static func read(account: String) -> String? {
        var q = query(account)
        q[kSecReturnData as String] = true
        q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess,
              let data = out as? Data else { return nil }
        return String(data: data, encoding: .utf8)
    }

    static func write(_ value: String, account: String) {
        let data = Data(value.utf8)
        let status = SecItemUpdate(query(account) as CFDictionary,
                                   [kSecValueData as String: data] as CFDictionary)
        if status == errSecItemNotFound {
            var add = query(account)
            add[kSecValueData as String] = data
            SecItemAdd(add as CFDictionary, nil)
        }
    }

    static func delete(account: String) {
        SecItemDelete(query(account) as CFDictionary)
    }
}
```

```swift
import AppKit
import MuDoCore

@MainActor
final class ChromeTabFocuser {
    static let chromeBundleID = "com.google.Chrome"

    var onAutomationDenied: (() -> Void)?
    private let queue = DispatchQueue(label: "dev.steve.MuDo.applescript")

    private enum ScriptResult<T: Sendable>: Sendable {
        case ok(T)
        case denied
        case failed
    }

    func focus(codeServer: URL, cwd: String, project: String) {
        let target = TabMatcher.targetURL(codeServer: codeServer, cwd: cwd)
        guard let chrome = NSWorkspace.shared.urlForApplication(withBundleIdentifier: Self.chromeBundleID) else {
            NSWorkspace.shared.open(target)
            return
        }
        guard !NSRunningApplication.runningApplications(withBundleIdentifier: Self.chromeBundleID).isEmpty else {
            openNewWindow(target, chrome: chrome)
            return
        }
        Task {
            switch await run(ChromeScripts.listTabs, parse: Self.parseTabs) {
            case .denied:
                onAutomationDenied?()
                openNewWindow(target, chrome: chrome)
                return
            case .failed:
                openNewWindow(target, chrome: chrome)
                return
            case let .ok(tabs):
                if let tab = TabMatcher.match(tabs: tabs, codeServer: codeServer, cwd: cwd, project: project) {
                    switch await run(ChromeScripts.focus(tab), parse: { _ in true }) {
                    case .ok: return
                    case .denied: onAutomationDenied?()
                    case .failed: break
                    }
                }
                switch await run(ChromeScripts.newWindow(target), parse: { _ in true }) {
                case .ok: return
                case .denied: onAutomationDenied?()
                case .failed: break
                }
                openNewWindow(target, chrome: chrome)
            }
        }
    }

    private func openNewWindow(_ url: URL, chrome: URL) {
        let process = Process()
        process.executableURL = URL(fileURLWithPath: "/usr/bin/open")
        process.arguments = ["-na", chrome.path, "--args", "--new-window", url.absoluteString]
        do {
            try process.run()
        } catch {
            NSWorkspace.shared.open(url)
        }
    }

    private func run<T: Sendable>(_ source: String,
                                  parse: @escaping @Sendable (NSAppleEventDescriptor) -> T) async -> ScriptResult<T> {
        await withCheckedContinuation { continuation in
            queue.async {
                guard let script = NSAppleScript(source: source) else {
                    continuation.resume(returning: .failed)
                    return
                }
                var error: NSDictionary?
                let output = script.executeAndReturnError(&error)
                if let error {
                    let code = error[NSAppleScript.errorNumber] as? Int ?? 0
                    continuation.resume(returning: code == -1743 ? .denied : .failed)
                    return
                }
                continuation.resume(returning: .ok(parse(output)))
            }
        }
    }

    nonisolated static func parseTabs(_ list: NSAppleEventDescriptor) -> [ChromeTab] {
        guard list.numberOfItems > 0 else { return [] }
        return (1...list.numberOfItems).compactMap { i in
            guard let item = list.atIndex(i), item.numberOfItems == 4,
                  let url = item.atIndex(3)?.stringValue else { return nil }
            return ChromeTab(windowID: Int(item.atIndex(1)?.int32Value ?? 0),
                             tabIndex: Int(item.atIndex(2)?.int32Value ?? 0),
                             url: url,
                             title: item.atIndex(4)?.stringValue ?? "")
        }
    }
}
```

```swift
import Foundation
import MuDoCore

struct URLSessionTransport: EventTransport {
    func events(url: URL, token: String) -> AsyncThrowingStream<SSEEvent, any Error> {
        AsyncThrowingStream { continuation in
            let task = Task {
                do {
                    var request = URLRequest(url: url)
                    // Idle timeout between packets; the daemon pings every 15 s.
                    request.timeoutInterval = 45
                    request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
                    request.setValue("text/event-stream", forHTTPHeaderField: "Accept")
                    let (bytes, response) = try await URLSession.shared.bytes(for: request)
                    let code = (response as? HTTPURLResponse)?.statusCode ?? 0
                    if code == 401 { throw StreamError.unauthorized }
                    guard code == 200 else { throw StreamError.http(code) }
                    var parser = SSEParser()
                    var chunk: [UInt8] = []
                    chunk.reserveCapacity(4096)
                    for try await byte in bytes {
                        chunk.append(byte)
                        if byte == 0x0A || byte == 0x0D {
                            for event in parser.feed(chunk) { continuation.yield(event) }
                            chunk.removeAll(keepingCapacity: true)
                        }
                    }
                    continuation.finish()
                } catch {
                    continuation.finish(throwing: error)
                }
            }
            continuation.onTermination = { _ in task.cancel() }
        }
    }
}

struct APIClient: Sendable {
    /// POST /v1/sessions/{id}/ack. 404 and 409 mean there is nothing left to ack.
    func ack(daemon: URL, token: String, sessionID: String) async -> Bool {
        var request = URLRequest(url: daemon.appending(path: "v1/sessions")
            .appending(path: sessionID)
            .appending(path: "ack"))
        request.httpMethod = "POST"
        request.timeoutInterval = 5
        request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        guard let (_, response) = try? await URLSession.shared.data(for: request),
              let code = (response as? HTTPURLResponse)?.statusCode else { return false }
        return code == 204 || code == 404 || code == 409
    }
}
```

```swift
    /// Pushes settings into the store and (re)builds connections whose config or token changed.
    func applySettings() {
        store.staleAfter = TimeInterval(settings.staleMinutes * 60)
        store.snoozeFor = TimeInterval(settings.snoozeMinutes * 60)
        store.setServers(settings.servers)
        let wanted = Dictionary(uniqueKeysWithValues: settings.servers.map { ($0.id, $0) })
        for (id, connection) in connections {
            if wanted[id] != connection.config || settings.token(for: id) != tokens[id] {

                connections[id] = nil
            }

            tokens[config.id] = token
            let connection = ServerConnection(
                config: config, token: token, store: store, transport: URLSessionTransport(),
                onAckRetry: { [weak self] keys in self?.retryAcks(keys) })
            connections[config.id] = connection
            connection.start()
        }
        tokens = tokens.filter { wanted[$0.key] != nil }
    }

        if row.session.state == .done {
            let token = tokens[config.id] ?? ""
            let key = row.id
            Task {
                let ok = await api.ack(daemon: config.daemonURL, token: token, sessionID: key.sessionID)
                if !ok { store.markAckFailed(key) }
            }
        }
        if let codeServer = config.codeServerURL {
            focuser.focus(codeServer: codeServer, cwd: row.session.cwd, project: row.session.project)
        }
    }

    func snooze(_ row: SessionRow) {
        store.snooze(row.id)
    }

    func togglePause() {
        if store.isPaused {
            store.resume()
        } else {
            store.pause(for: 3600)
        }
    }

    /// Handles `mudo://add?...`. Returns false for anything else.
    @discardableResult
    func handle(url: URL) -> Bool {
        guard let draft = AddLink.parse(url) else { return false }
        settings.add(draft)
        applySettings()
        return true
    }

    private func retryAcks(_ keys: [SessionKey]) {
        for key in keys {
            guard let config = settings.servers.first(where: { $0.id == key.serverID }) else { continue }
            let token = tokens[config.id] ?? ""
            Task { _ = await api.ack(daemon: config.daemonURL, token: token, sessionID: key.sessionID) }
        }
    }

    private func reconnectAll() {
        for connection in connections.values { connection.reconnectNow() }
    }

    private func startTimer() {
        let timer = Timer(timeInterval: 1, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.store.tick() }
        }
        timer.tolerance = 0.1
        RunLoop.main.add(timer, forMode: .common)
        self.timer = timer
    }

    private func watchWakeAndNetwork() {
        NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didWakeNotification, object: nil, queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated { self?.reconnectAll() }
        }
        pathMonitor.pathUpdateHandler = { [weak self] path in
            let satisfied = path.status == .satisfied
            Task { @MainActor in self?.networkChanged(satisfied: satisfied) }
        }
        pathMonitor.start(queue: .main)
    }

    private func networkChanged(satisfied: Bool) {
        defer { pathSatisfied = satisfied }
        // The first callback reports the current state; only react to later changes.
        guard pathSatisfied != nil else { return }
        if satisfied { reconnectAll() }
    }
}
```

```swift
/// Hosting view that reports hover even when MuDo is not the active app,
/// accepts the first click, and lets the background drag the panel.
final class HoverHostingView<Content: View>: NSHostingView<Content> {
    var onHover: ((Bool) -> Void)?
    private var hoverArea: NSTrackingArea?

    override var mouseDownCanMoveWindow: Bool { true }

    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    override func updateTrackingAreas() {
        super.updateTrackingAreas()
        if let hoverArea { removeTrackingArea(hoverArea) }
        let area = NSTrackingArea(rect: .zero,
                                  options: [.mouseEnteredAndExited, .activeAlways, .inVisibleRect],
                                  owner: self, userInfo: nil)
        addTrackingArea(area)
        hoverArea = area
    }

    override func mouseEntered(with event: NSEvent) {
        super.mouseEntered(with: event)
        onHover?(true)
    }

    override func mouseExited(with event: NSEvent) {
        super.mouseExited(with: event)
        onHover?(false)
    }
}

@MainActor
@Observable
final class PanelState {
    private(set) var hovering = false
    private(set) var pinned = false
    @ObservationIgnored var onSizeChange: ((CGSize) -> Void)?
    @ObservationIgnored private var collapseTask: Task<Void, Never>?

    var isExpanded: Bool { hovering || pinned }

    func pointerEntered() {
        collapseTask?.cancel()
        hovering = true
    }

    func pointerExited() {
        collapseTask?.cancel()
        collapseTask = Task { [weak self] in
            try? await Task.sleep(for: .seconds(1.5))
            guard !Task.isCancelled else { return }
            self?.hovering = false
        }
    }

    func togglePinned() {
        pinned.toggle()
    }

    func contentSizeChanged(_ size: CGSize) {
        onSizeChange?(size)
    }
}

@MainActor
final class PanelController {
    private static let positionKey = "panelTopLeft"

    private let panel = FloatingPanel()
    private let state = PanelState()
    private let defaults: UserDefaults

    init(model: AppModel, defaults: UserDefaults = .standard) {
        self.defaults = defaults
        let host = HoverHostingView(rootView: RootView(model: model, panel: state))
        host.sizingOptions = []
        host.onHover = { [weak state] inside in
            if inside { state?.pointerEntered() } else { state?.pointerExited() }
        }
        panel.contentView = host
        state.onSizeChange = { [weak self] size in self?.resize(to: size) }
        NotificationCenter.default.addObserver(forName: NSWindow.didMoveNotification, object: panel, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.saveTopLeft() }
        }
        NotificationCenter.default.addObserver(forName: NSApplication.didChangeScreenParametersNotification, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.place() }
        }
    }

    func show() {
        place()
        panel.orderFrontRegardless()
    }

    private func resize(to size: CGSize) {
        guard size.width > 0, size.height > 0 else { return }
        var frame = panel.frame
        let top = frame.maxY
        frame.size = size
        frame.origin.y = top - size.height
        panel.setFrame(frame, display: true)
    }

    private func saveTopLeft() {
        defaults.set([Double(panel.frame.minX), Double(panel.frame.maxY)], forKey: Self.positionKey)
    }

    private func place() {
        var saved: CGPoint?
        if let xy = defaults.array(forKey: Self.positionKey) as? [Double], xy.count == 2 {
            saved = CGPoint(x: xy[0], y: xy[1])
        }
        guard let topLeft = PanelPlacement.topLeft(
            saved: saved,
            screens: NSScreen.screens.map(\.visibleFrame),
            main: NSScreen.main?.visibleFrame,
            width: max(panel.frame.width, 160)) else { return }
        panel.setFrameTopLeftPoint(topLeft)
    }
}
```

```swift
struct Blink: ViewModifier {
    let active: Bool
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    @ViewBuilder
    func body(content: Content) -> some View {
        if !active {
            content
        } else if reduceMotion {
            content.overlay(RoundedRectangle(cornerRadius: 8).stroke(.green, lineWidth: 2))
        } else {
            TimelineView(.periodic(from: .now, by: 0.5)) { context in
                content.opacity(Int(context.date.timeIntervalSinceReferenceDate * 2) % 2 == 0 ? 1 : 0.3)
            }
        }
    }
}
```

````markdown
## Add a server

Run `mudod install` on the server, then open the printed `mudo://add?...` link on the Mac (or paste it in Settings). Append `&code_server=<url-encoded code-server URL>` to the link, or fill "code-server URL" in Settings, so that clicking a session can focus its Chrome window.

## Permissions

- First click on a session asks for Automation access to Google Chrome. If denied, MuDo opens a new Chrome window instead, and the menu shows "Allow MuDo to control Chrome…".
- Tokens are stored in the Keychain. Each rebuild changes the ad-hoc signature, so macOS may ask once to allow Keychain access after an update.
````

3. ⏸ on a blinking row stops its blink for the snooze duration; "Pause blinking (1 h)" stops all blinking; "Resume blinking" restores it.
4. Wrong token in Settings → row "<name> token invalid", no reconnect attempts; fixing the token reconnects.
5. Stop `mudod fake` → "<name> offline", rows dimmed with `?`, no blinking; restart it → reconnects within 30 s; sleep/wake the Mac → reconnects immediately.
6. Real server: start `claude` in a code-server terminal in project A (Chrome window 1) and project B (Chrome window 2). Finish a prompt in A, switch to window 2, click A's row in MuDo → window 1 comes to front with the right tab, the row goes `idle` (ack).
7. Close window 1, click A's row again → a new Chrome window opens on `<code-server>/?folder=<cwd of A>`.
8. Deny Automation (System Settings → Privacy & Security → Automation → MuDo → Chrome off), click a row → new Chrome window opens, menu shows "Allow MuDo to control Chrome…".

10. Reduce Motion on (System Settings → Accessibility → Display) → blinking rows show a steady green outline instead of pulsing.
