# Idle fold Implementation Plan

> **For agentic workers:** executed with `/mudo-task` (one task). Steps use checkbox (`- [ ]`) syntax.

**Goal:** A long list of idle sessions no longer buries the ones that matter. Only the three most recent idle sessions show, with a row to reveal the rest, and idle sessions older than a chosen age are hidden.

**Architecture:** MuDoCore decides which rows show: `SessionStore.rows` drops idle sessions past the age limit, and a pure `IdleFold` splits the sorted rows into the visible ones and a hidden count. The MuDo target keeps the "show all" toggle in `PanelState`, renders the fold row, and adds the setting.

**Tech Stack:** Swift 6, swift-testing (MuDoCore), SwiftUI (MuDo).

## Global Constraints

- Age limit: `SessionStore.hideIdleAfter: TimeInterval?` (nil = never). A row whose bucket is `.idle` and whose `elapsed >= hideIdleAfter` is left out of `rows` (and so of everything built on `rows`). Other buckets are never hidden by age.
- Setting (UserDefaults): `hideIdleAfterHours` (Int, default `24`; `0` means never; allowed values `0, 1, 4, 12, 24, 72, 168`; any other stored value reads as `24`). `AppModel.applySettings()` sets `store.hideIdleAfter` (`nil` for 0, else hours × 3600). Settings section `Widget` gets a Picker `Hide idle sessions after` with options `Never`, `1 hour`, `4 hours`, `12 hours`, `1 day`, `3 days`, `1 week`, and caption `An idle session stays listed while its agent runs. Older ones are hidden here, not closed.`
- Fold: `public enum IdleFold { public static let shown = 3; public static func split(_ rows: [SessionRow], showAll: Bool) -> (rows: [SessionRow], hidden: Int) }`. Rows keep their order. Non-idle rows always show. With `showAll` false, only the first `shown` idle rows (the newest, as `rows` sorts them) show and `hidden` is the number of idle rows left out; with `showAll` true, all rows show and `hidden` is 0. A fold that would hide nothing returns `hidden` 0.
- UI: `SessionListView` renders `IdleFold.split(...).rows`; when `hidden > 0`, a last row (after the sessions, before server problem rows) reads `+<n> idle` in the caption/secondary style, and clicking it sets show-all. When show-all is on and more than `shown` idle rows exist, the last row reads `Show fewer` and clicking it clears show-all. Show-all lives in `PanelState` (`showAllIdle`, default false) and resets to false when the panel collapses.
- README (Usage): one sentence on the fold and the setting.
- Keep the MuDo target thin; logic and tests in MuDoCore.
